## Решения, принятые при реализации

- snmp4j 3.9.7 подключён в `server` в области compile уже в T1.01 (§3). Владелец зависимости: модуль snmp, задача 4.
- Тестовая зависимость `server` → `emulators` с исключением `slf4j-simple`.
- Отключён `UserDetailsServiceAutoConfiguration` до T1.05, чтобы пароль по умолчанию не попадал в лог.

- Ключ секретов в тестах: временный каталог JVM через `TestPostgres.properties()`, `application-test.yml` его не задаёт (решение architect, см. допущение A-04).
