## Решения, принятые при реализации

- Найдена скрытая проблема T1.01: `SmokeTest` падает в `verify` при втором тесте с той же конфигурацией контекста (контекст берётся из кеша, строка `Started SmokeTest in` не выводится). Воспроизведено architect. Решение: `@DirtiesContext(BEFORE_CLASS)` на `SmokeTest`. Карточка T1.02 разрешает это изменение.
- Имена ограничений (`device_ip_check`, `trap_rule_check`, `trap_rule_check1`, `alarm_check` и т.п.) не задаются явно: PostgreSQL присваивает их по дословному DDL. Тест сверяет эти автоимена (допущение A-17).
- Для PostgreSQL 18.6 с Flyway 12.4.0 в режиме `-o` синтаксис DDL проверен architect до реализации.
- Тесты не используют `TestDb` (появится в T1.03), поэтому тестовые строки остаются в общей БД JVM (см. follow-up).

## Не проверено

- Совместимость с PostgreSQL 16 и 17 (заявлена в §4). Прогон только на встроенном PostgreSQL 18.6.
- Windows (PostgreSQL windows-amd64, Flyway и тесты). Проверено только на Linux x86_64.
- Значения настроек `session.timeout_minutes=720`, `auth.lock_attempts=5`, `auth.lock_minutes=15` и минимальная длина пароля 8 символов не подтверждены заказчиком. В ТЗ их нет (A-14, A-15).
- Тесты в общей БД JVM могут влиять друг на друга, если появятся тесты, которые считают все строки таблицы (см. follow-up 3, 6).

Замечания ревью, не блокирующие приёмку (передаются architect для карточек T1.03, T1.07, T3.x; в реестр не внесены, это не допущения):
1. `defaultSettings` сверяет всю `system_setting`. Хрупко после T1.07. Сверять по ключам или через `TestDb`.
2. `select relkind` по `relname` без схемы (строка 99). Использовать `'public.check_result'::regclass`.
3. Строка остаётся в `check_result_default`. По POLL-09 это признак сбоя. Тесты здоровья разделов (T3.x) могут зависеть от порядка. Удалять в `finally` или очищать через `TestDb`.
4. `getServerErrorMessage()` может вернуть `null`, тогда будет NPE вместо понятной ошибки.
5. Не проверяется число строк в `update` (строки 116, 118).
6. Тестовые данные остаются в общей БД JVM. Учитывать в `@IntegrationTest` (T1.03).
